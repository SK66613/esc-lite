# Escalita Lite — интерактивный Mini App Constructor (demo)

Рабочий фронтенд-прототип конструктора Telegram Mini App по предоставленным референсам.

## Что работает

- Главная панель конструктора
- Выбор шаблонов по категориям
- Редактор / предпросмотр
- Sales Passport
- QR Sales
- Проверка подписки
- Публикация в демо-режиме
- Share (копирует тестовую ссылку)
- Клиентский Mini App в модальном окне
- Изменение настроек и переключателей
- Состояние сохраняется в `localStorage`
- Никаких реальных API и backend-зависимостей

## Запуск

### Самый простой

Откройте `index.html` двойным кликом в браузере.

### Через локальный сервер

```bash
python3 -m http.server 8080
```

и откройте `http://localhost:8080`.

## Куда дальше подключать API

Удобные точки для замены mock-логики:

- загрузка / сохранение приложения;
- список шаблонов;
- publish;
- проверка подписки;
- QR issue / scan;
- Telegram initData;
- загрузка ассетов;
- реальный клиентский Mini App.

Текущий код специально оставлен без фреймворков, чтобы прототип можно было быстро положить в любой repo и потом либо оставить как Vanilla SPA, либо перенести на React/Vue/Svelte.
